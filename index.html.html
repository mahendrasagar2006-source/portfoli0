Mana Raithu Nestam — Smart Crop Advisory

An AI-powered farming platform built for Telangana farmers. It recommends the best crop to grow based on local temperature, previous crop rotation, soil conditions, and other agricultural parameters — helping farmers make data-driven decisions and reduce crop failure.

  • Crop recommendation engine using temperature, rainfall & previous crop data
  • Integrated government scheme information relevant to the suggested crop
  • Bilingual support — accessible in Telugu for local farming communities
  • Simple, mobile-friendly UI designed for farmers with low tech literacy
  • Deployed live on Vercel — accessible from any device
