Project 01
NeuroStudy — Virtual Brain Learning Simulator

A full-stack AI-powered learning platform that improves memory retention using neuroscience — the forgetting curve, active recall, and biometric relaxation techniques.

Core Features
  • Subject cards showing memory retention % per topic
  • Forgetting curve graph visualization via Recharts
  • "Revise Now" alerts for topics about to be forgotten
  • Study streak tracker to monitor consistency
🧘 Brain Break Feature
  • Webcam-based Python script served via Flask API
  • Eye blink detection using OpenCV + dlib
  • Mini-game: blink in sync with on-screen rhythm (30s)
  • Scientifically relaxes eye muscles and restores focus
  • Generates shareable achievement badge with score
⏱ Smart Trigger: Activates via "Take a Brain Break" button after a 25-minute Pomodoro session.

Project 02
Smart Crop Advisory System

A data-driven web application built for Smart India Hackathon (SIH) that helps farmers make informed crop decisions by analysing location, soil type, weather conditions, and water availability — reducing yield loss and financial risk.

Key Features
  • Crop recommendation with match accuracy score
  • Profit estimation and ROI analysis per crop
  • Fertilizer and irrigation planning guidance
  • Pest & disease management and soil health insights
  • Crop rotation planning and market price trend analysis
  • Government schemes information for farmers
  • Bilingual support — English & Telugu
🚜 SIH Problem Statement: Farmers struggle to select the right crop due to soil variation, unpredictable weather, and lack of reliable agricultural guidance.
